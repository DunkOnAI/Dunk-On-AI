## Dev setup (Flask + React Vite)

Backend:

1. `python -m venv venv`
2. `venv\\Scripts\\activate`
3. `pip install -r requirements.txt`
4. `flask run`

Frontend:

1. `cd Frontend`
2. `npm install`
3. `npm run dev`

The Vite dev server proxies `/api` requests to Flask on `http://127.0.0.1:5000`.
